# Blender for Directors

Make 3D shots by talking. Use them to guide your AI videos.

## Start here

**1.** Open the ChatGPT app on your computer.

**2.** Copy this and send it:

```
Read https://github.com/ayotho/blender-for-directors and follow AGENTS.md. Set me up.
```

**3.** Do what it says. It goes one step at a time.

That's it. 🎬
